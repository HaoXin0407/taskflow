# 接口清单

所有接口前缀 `/api`，除标注「免认证」外均需在 Header 携带 `Authorization: Bearer {token}`。

---

## 1. 认证管理

| 方法 | 路径 | 说明 | 权限 | 免认证 |
|------|------|------|------|--------|
| POST | `/auth/login` | 登录 | - | ✅ |
| POST | `/auth/register` | 注册 | - | ✅ |
| GET | `/auth/me` | 当前用户信息 | 登录 | |
| POST | `/auth/password` | 修改密码 | 登录 | |
| POST | `/auth/logout` | 退出 | 登录 | |

**登录请求体**：
```json
{ "username": "admin", "password": "123456" }
```

**登录响应**：
```json
{
  "code": 200,
  "msg": "登录成功",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiJ9...",
    "tokenPrefix": "Bearer ",
    "userId": 1,
    "username": "admin",
    "nickname": "系统管理员",
    "dept": "技术部",
    "roles": ["ADMIN"],
    "permissions": ["dashboard", "ticket:list", "system:user", ...],
    "menus": [ { "permCode": "ticket", "permName": "工单中心", "path": "/ticket", ... } ],
    "unreadCount": 2
  }
}
```

## 2. 工单管理

| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| GET | `/ticket/page` | 分页查询 | 登录 |
| GET | `/ticket/{id}` | 工单详情（含轨迹+评论） | 登录 |
| POST | `/ticket` | 创建工单 | `ticket:add` |
| PUT | `/ticket` | 修改工单 | 创建人 + 待受理状态 |
| DELETE | `/ticket/{id}` | 删除工单 | 管理员或创建人 |
| POST | `/ticket/{id}/action` | 工单流转 | 依动作而定 |
| POST | `/ticket/{id}/comment` | 添加评论 | 登录 |
| GET | `/ticket/{id}/actions` | 当前可用动作 | 登录 |

**分页查询参数**：
```
pageNum=1&pageSize=10&keyword=&status=&type=&priority=&mine=true
```

**流转请求体**：
```json
{
  "action": "ACCEPT",
  "remark": "已受理，开始排查",
  "assigneeId": null
}
```

**action 可选值**：

| action | 含义 | 允许的源状态 | 目标状态 | 权限要求 |
|--------|------|-------------|---------|---------|
| `ACCEPT` | 受理 | 待受理 | 处理中 | ticket:handle |
| `TRANSFER` | 转派 | 处理中、待确认 | 状态不变 | ticket:handle |
| `SUBMIT` | 提交 | 处理中 | 待确认 | 当前处理人 |
| `CONFIRM` | 确认验收 | 待确认 | 已完成 | 提单人 |
| `REJECT` | 驳回 | 处理中、待确认 | 处理中 | 当前处理人/提单人 |
| `CLOSE` | 关闭归档 | 待受理、已完成 | 已关闭 | ticket:handle |
| `REOPEN` | 重开 | 已完成、已关闭、已驳回 | 处理中 | ticket:handle |

> 非法流转会返回 `code: 3002`，提示"当前状态为「X」，不能执行「Y」操作"

## 3. 审批管理

| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| GET | `/approval/page` | 分页查询 | 登录 |
| GET | `/approval/{id}` | 审批详情（含审批链） | 登录 |
| POST | `/approval` | 提交审批 | `approval:audit` |
| POST | `/approval/audit` | 审批（通过/驳回） | 当前节点审批人 |
| POST | `/approval/{id}/cancel` | 撤销 | 申请人本人 |
| GET | `/approval/todo/count` | 待我审批数 | 登录 |

**分页 scope 参数**：

| scope | 含义 |
|-------|------|
| `mine` | 我发起的（默认） |
| `todo` | 待我审批 |
| `done` | 我处理过的 |
| `all` | 全部（仅管理员有效，非管理员自动降级为 mine） |

**提交审批请求体**：
```json
{
  "title": "10月14日加班申请",
  "bizType": "OVERTIME",
  "reason": "因版本上线需要",
  "amount": null,
  "approverIds": [2, 1]
}
```
> `approverIds` 顺序即审批顺序，[2,1] 表示先主管后总监，形成多级串行审批

**审批请求体**：
```json
{ "approvalId": 1, "pass": true, "comment": "同意" }
```

## 状态码约定

| code | 含义 |
|------|------|
| 200 | 成功 |
| 400 | 请求参数错误 |
| 401 | 未登录或登录已过期 |
| 403 | 无访问权限 |
| 500 | 系统内部错误 |
| 1001 | 账号或密码错误 |
| 1002 | 账号已被禁用 |
| 1005 | 用户名已存在 |
| 1006 | 原密码错误 |
| 3001 | 工单不存在 |
| 3002 | 当前状态不允许该操作 |
| 3003 | 只能受理指派给自己的工单 |
| 4001 | 审批单不存在 |
| 4002 | 审批单已结束，无法重复处理 |
| 4003 | 您不是当前节点的审批人 |

## 在线调试

后端启动后访问 **http://localhost:8080/api/doc.html**

先调 `/auth/login` 拿到 token，点击右上角「Authorize」填入 `Bearer {token}`，之后所有接口即可直接调试。
